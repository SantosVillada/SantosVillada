# Santos Villada

Landing personal de Santos Villada, desarrollador web especializado en construir productos digitales, automatizaciones y aplicaciones web con herramientas modernas e inteligencia artificial.

## Stack

- Next.js
- React
- TypeScript
- CSS

## Desarrollo local

```bash
npm install
npm run dev
```

La landing usa `mailto:scvillada@gmail.com` para preparar las consultas sin requerir credenciales externas.

## Configuración opcional

Cuando el dominio de producción esté confirmado, definir `NEXT_PUBLIC_SITE_URL` para activar canonical, sitemap y URL del robots.
